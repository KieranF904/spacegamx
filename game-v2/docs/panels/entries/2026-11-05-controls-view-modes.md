The camera is now its own setting (Settings, Gameplay, View: With controls / North up / Follow heading; the ` key switches it for the session), so all four pairings fly. Before: only mouse-steer north up and helm heading-up (both unchanged, and still what an older save gets). After, each one holding W: mouse-steer north up, helm heading-up, helm with the view north up, and mouse-steer heading-up, where the aim is pinned in space (the drawn ring cursor swings round above the nose as the view turns) and W pushes along the ship.
