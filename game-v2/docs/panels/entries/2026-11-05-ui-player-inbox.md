The join screen now has a player inbox for signed-in pilots (guests don't get one). An unread admin message shows as an amber banner above everything, with its subject and a Read button, until it's read. The Join button gets a "✉ N new" badge, and below it the inbox shows the unread count, the message list and a reader. Admins get a Send message form: a username or everyone, a subject and plain text, with a "show as a banner" option, plus a list of what they've sent and how many have read it. Shots were taken on a scratch dev lobby with made-up pilots, so there's no before.
